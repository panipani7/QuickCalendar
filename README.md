# Quick Calendar

macOS のメニューバーで今月のカレンダーをすぐ確認できるユーティリティ。

- メニューバーのアイコンをクリックすると今月のカレンダーを表示
- 日曜始まり・今日の日付をハイライト表示
- 日本の祝日に対応（jpholiday）
- 前月・翌月へのナビゲーション
- Mac にログインしたとき自動で起動する設定（右クリックメニューから切り替え）
- Dock には表示されないメニューバー常駐アプリ

## インストール方法（かんたん・ビルド不要）

ターミナルを使わずにインストールできます。ほとんどの方はこちらの方法で大丈夫です。

1. [QuickCalendar.zip](QuickCalendar.zip) をダウンロードしてダブルクリックで解凍
2. 出てきた **QuickCalendar.app** を **アプリケーション** フォルダにドラッグ
3. アプリケーションフォルダの QuickCalendar を右クリックして「開く」を選ぶ

起動すると Dock には表示されず、画面右上のメニューバーにカレンダーアイコンが現れます。

> **「開発元を確認できません」と警告が出た場合**
> **システム設定 → プライバシーとセキュリティ** を開き、画面下部の「このまま開く」を押してください。

2回目以降は以下のいずれかの方法で起動できます。

- **Launchpad** を開いて「Quick Calendar」をクリック
- **Spotlight**（⌘スペース）で「QuickCalendar」と入力して Return
- **Finder → アプリケーション** フォルダで「QuickCalendar」をダブルクリック

## Mac にログインしたとき自動で起動させる

毎回手で起動しなくて済むように、ログイン時の自動起動をアプリ内から設定できます。

1. メニューバーのカレンダーアイコンを **右クリック**
2. 「**ログイン時に自動起動**」をクリック（チェックマークが付けば ON）

もう一度クリックするとチェックが外れて OFF に戻ります。ON にすると `~/Library/LaunchAgents` に設定ファイルが作成され、Mac にログインしたときに自動でアプリが起動するようになります。

## その他のメニュー操作

- アイコンを **左クリック** … カレンダーの表示 / 非表示
- アイコンを **右クリック** … メニューを表示（自動起動の切り替え・アプリの終了）

## 開発者向け

### ソースからビルドしてインストールする

ターミナルで以下のコマンドを一度実行すると、ビルドしてアプリケーションフォルダにインストールし、自動で起動します。

```sh
./install-app.sh
```

### ターミナルから直接起動する

```sh
./run.sh
```

初回実行時に仮想環境の作成と依存パッケージのインストールが自動で行われ、その後アプリが起動します。

### アプリをビルドする

`install-app.sh` が py2app でのビルドとインストールをまとめて行います。ビルドだけ行う場合は次の通りです。

```sh
./venv/bin/python -m pip install py2app
./venv/bin/python setup.py py2app
open dist/QuickCalendar.app
```
