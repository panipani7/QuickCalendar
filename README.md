# Quick Calendar

macOS のメニューバーで今月のカレンダーをすぐ確認できるユーティリティ。

- メニューバーのアイコンをクリックすると今月のカレンダーを表示
- 日曜始まり・今日の日付をハイライト表示
- 日本の祝日に対応（2000〜2099年・オフライン計算、通信は一切なし）
- 前月・翌月へのナビゲーション
- Mac にログインしたとき自動で起動する設定（カレンダー下部の歯車メニューから切り替え）
- Dock には表示されないメニューバー常駐アプリ
- Swift + SwiftUI 製のネイティブアプリ（約250KB・外部依存なし）

**動作環境: macOS 13 (Ventura) 以降**

## インストール方法（かんたん・ビルド不要）

ターミナルを使わずにインストールできます。ほとんどの方はこちらの方法で大丈夫です。

1. [QuickCalendar.zip](QuickCalendar.zip) をダウンロードしてダブルクリックで解凍
2. 出てきた **QuickCalendar.app** を **アプリケーション** フォルダにドラッグ
3. アプリケーションフォルダの QuickCalendar を右クリックして「開く」を選ぶ

起動すると Dock には表示されず、画面右上のメニューバーにカレンダーアイコンが現れます。

> **「開発元を確認できません」と警告が出た場合**
> **システム設定 → プライバシーとセキュリティ** を開き、画面下部の「このまま開く」を押してください。

2回目以降は以下のいずれかの方法で起動できます。

- **Launchpad** を開いて「Quick Calendar」をクリック
- **Spotlight**（⌘スペース）で「QuickCalendar」と入力して Return
- **Finder → アプリケーション** フォルダで「QuickCalendar」をダブルクリック

## Mac にログインしたとき自動で起動させる

毎回手で起動しなくて済むように、ログイン時の自動起動をアプリ内から設定できます。

1. メニューバーのカレンダーアイコンをクリックしてカレンダーを開く
2. 右下の **歯車アイコン** をクリック
3. 「**ログイン時に自動起動**」をクリック（チェックが付けば ON）

もう一度クリックすると OFF に戻ります。設定は macOS 標準のログイン項目として登録されるため、**システム設定 → 一般 → ログイン項目** にも表示されます。

## 画面の操作

- メニューバーのアイコンをクリック … カレンダーの表示 / 非表示
- **‹ ›** ボタン … 前月 / 翌月へ移動
- **今日** ボタン … 今月に戻る
- 祝日（赤いドット付きの日付）にマウスを乗せると祝日名を表示
- 右下の **歯車アイコン** … ログイン時の自動起動の切り替え・アプリの終了

## 開発者向け

実装は Swift + SwiftUI（MenuBarExtra）で、[QuickCalendarSwift/](QuickCalendarSwift/) に SwiftPM パッケージとして置いています。祝日判定は外部ライブラリを使わず自前計算です（2000〜2099年対応、jpholiday との突き合わせ検証済み）。

### ビルドとインストール

Xcode は不要です（Command Line Tools の Swift でビルドできます）。

```sh
./build-app.sh            # dist/QuickCalendar.app を生成
./build-app.sh --install  # ビルド後 /Applications にインストールして起動
```

### アイコンを差し替える

- `icon.svg` … メニューバーアイコンのマスター素材
- `appicon.svg` … Finder に表示されるアプリアイコンのマスター素材（.icns はビルド時に自動生成）

`icon.svg` を変更したら以下でメニューバー用 PNG を再生成してビルドしてください。`appicon.svg` はビルドするだけで反映されます。

```sh
sips -s format png -z 22 22 icon.svg --out icon.png
sips -s format png -z 44 44 icon.svg --out icon@2x.png
./build-app.sh --install
```

### 旧 Python 版について

初期実装（Python + PyObjC + py2app）は Swift 版への移植完了に伴い削除しました。必要な場合は git 履歴から参照できます。
