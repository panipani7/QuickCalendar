# Quick Calendar

macOS のメニューバーで今月のカレンダーをすぐ確認できるユーティリティ。

- メニューバーのアイコンをクリックすると今月のカレンダーを表示
- 日曜始まり・今日の日付をハイライト表示
- 日本の祝日に対応（jpholiday）
- 前月・翌月へのナビゲーション
- Dock には表示されないメニューバー常駐アプリ

## インストール（推奨）

ターミナルで以下のコマンドを一度実行すると、アプリケーションフォルダにインストールされて自動で起動します。

```sh
./install-app.sh
```

インストール後は、ターミナルを使わずに以下のいずれかの方法で起動できます。

- **Launchpad** を開いて「Quick Calendar」をクリック
- **Spotlight**（⌘スペース）で「QuickCalendar」と入力して Return
- **Finder → アプリケーション** フォルダで「QuickCalendar」をダブルクリック

起動すると Dock には表示されず、画面右上のメニューバーにカレンダーアイコンが現れます。

### Mac にログインしたとき自動で起動させる

毎回手で起動しなくて済むように、ログイン時の自動起動を設定できます。

1. **システム設定** を開く
2. **一般 → ログイン項目と機能拡張** を選ぶ
3. 「ログイン時に開く」の **＋** ボタンを押して、アプリケーションフォルダの **QuickCalendar** を追加

## zip からインストールする場合（ビルド不要）

ビルド済みの [QuickCalendar.zip](QuickCalendar.zip) をダウンロードして使うこともできます。

1. `QuickCalendar.zip` をダウンロードしてダブルクリックで解凍
2. 出てきた **QuickCalendar.app** を **アプリケーション** フォルダにドラッグ
3. QuickCalendar を右クリックして「開く」を選ぶ

初回起動時に「開発元を確認できません」と警告が出た場合は、**システム設定 → プライバシーとセキュリティ** を開き、画面下部の「このまま開く」を押してください。

## 開発者向け

### ターミナルから直接起動する

```sh
./run.sh
```

初回実行時に仮想環境の作成と依存パッケージのインストールが自動で行われ、その後アプリが起動します。

### アプリをビルドする

`install-app.sh` が py2app でのビルドとインストールをまとめて行います。ビルドだけ行う場合は次の通りです。

```sh
./venv/bin/python -m pip install py2app
./venv/bin/python setup.py py2app
open dist/QuickCalendar.app
```
